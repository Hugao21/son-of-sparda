# Son of Sparda
 
Portfólio fictício do personagem **Dante** (Devil May Cry), construído como site estático com [Hugo](https://gohugo.io/), para a disciplina PMR3304 - Sistemas de Informação.
 
> Projeto acadêmico e não-oficial. Devil May Cry, Dante e demais personagens são propriedade da Capcom — este site é um trabalho de fã, sem fins comerciais.
 
## 🔗 Acesso
 
- **Site (GitLab Pages):** https://son-of-sparda-5a2eb3.e.usp.br
- **Espelho público (GitHub Pages):** https://hugao21.github.io/son-of-sparda/
- **Repositório oficial:** GitLab da USP
## 📖 Sobre o projeto
 
O site funciona como um dossiê do escritório *Devil May Cry*, organizado em quatro seções:
 
| Página | Conteúdo |
|---|---|
| **Home** | Apresentação geral de Dante |
| **Sobre** | Biografia, personalidade e transformações demoníacas |
| **Arsenal** | Armas brancas, armas de fogo e estilos de combate |
| **Personagens** | Perfis de Lady, Nero, Trish e Vergil |
 
## 🛠️ Tecnologias
 
- [Hugo](https://gohugo.io/) — gerador de site estático
- HTML5 semântico (`header`, `nav`, `main`, `section`, `article`, `footer`)
- CSS puro, com Flexbox para o layout e media queries para responsividade
- GitLab CI/CD → deploy automático no GitLab Pages
- GitHub Actions → espelho público no GitHub Pages
